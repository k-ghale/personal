Grokking Algorithms – Code & Examples

This repository contains code implementations and learning resources based on the concepts from the book Grokking Algorithms: An Illustrated Guide for Programmers and Other Curious People by Aditya Y. Bhargava. Grokking Algorithms is a beginner-friendly guide to fundamental algorithms and how they work in practice, using clear illustrations and annotated Python examples.

📌 Project Overview

The purpose of this project is to organize practical, hands-on code examples that illustrate core algorithmic techniques introduced in Grokking Algorithms — from basic searching and sorting to graph traversal and dynamic programming.

Each chapter’s folder focuses on a specific topic or family of algorithms. These implementations are great for:

learning how the algorithms work from code,

comparing performance (e.g. Big O time/space),

experimenting and modifying the algorithm for deeper understanding.

Note: This project is intended as an educational reference and not production-grade library code.

📂 Repository Structure

Here’s how this project is organized:

grokkingAlgorithm/
├── Chapter1/            # Binary search, Big O notation
├── Chapter2/            # Arrays, linked lists, selection sort
├── Chapter3/            # Recursion basics
├── Chapter4/            # Quicksort implementation
├── Chapter5/            # Hash tables/dictionaries
├── Chapter6/            # Graphs & BFS
├── Chapter7/            # Dijkstra’s shortest path
├── Chapter8/            # Greedy algorithms
├── Chapter9/            # Dynamic programming
├── Chapter10/           # K-Nearest Neighbors (KNN)
└── README.md


Each folder contains example code files and (optionally) notes or explanations for the algorithms in that chapter.

🚀 Getting Started

Clone this repo

git clone https://github.com/k-ghale/personal.git


Navigate to the GrokkingAlgorithms folder

cd personal/grokkingAlgorithm


Run the code

Most folders include Python scripts you can run with:

python filename.py

🧠 What You’ll Learn

Working through this repo you’ll implement and explore:

🔍 Binary Search — Efficiently find elements in sorted lists

📈 Big O Notation — Compare algorithm performance

🔄 Recursion — Solve problems with functions calling themselves

⚖️ Sorting Algorithms — e.g. Quicksort

📊 Hash Tables — Key-value stores with fast lookups

🌐 Graphs & Search — BFS and shortest path algorithms (e.g., Dijkstra)

💡 Greedy Methods — Solve optimization problems step-by-step

📌 Dynamic Programming — Break problems into overlapping subproblems

🔎 K-Nearest Neighbors (KNN) — Intro to simple machine-learning algorithm

These concepts are foundational for technical interviews, computer science courses, and real-world problem solving.
