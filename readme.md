# Grokking Algorithm 

Practice implementations of algorithms from ***Grokking Algorithms* by Aditya Y. Bhargava**.

This repository focuses on learning algorithms through clear, code examples.

## Chapters included

### Chapter 1: Binary Search

* Introduction to binary search
* Understanding Big O notation

### Chapter 2: Arrays & Linked Lists

* Arrays vs linked lists
* Selection sort

### Chapter 3: Recursion

* Recursion basics
* Call stack

### Chapter 4: Quicksort

* Divide and conquer strategy
* Quicksort implementation

### Chapter 5: Hash Tables

* Hash functions
* Dictionaries and lookups

### Chapter 6: Graphs & Breadth‑First Search (BFS)

* Graph representation
* Shortest path with BFS

### Chapter 7: Dijkstra’s Algorithm

* Weighted graphs
* Shortest path algorithm

### Chapter 8: Greedy Algorithms

* Approximation techniques
* Optimization problems

### Chapter 9: Dynamic Programming

* Overlapping subproblems
* Memoization

### Chapter 10: K‑Nearest Neighbors (KNN)

* Basic machine learning concept
* Similarity and distance

Each chapter is organized into its own folder with example code.
